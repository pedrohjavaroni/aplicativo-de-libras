# Animações capturadas

Coloque aqui os arquivos `.json` gerados no **Estúdio de captura** (`captura.html`)
a partir dos vídeos da intérprete, e aponte para eles no `dados/dicionario.json`:

```json
{ "id": "obrigado", "glosa": "OBRIGADO", "palavras": ["obrigado", "obrigada"], "animacao": "dados/sinais/obrigado.json" }
```

Letras do alfabeto manual usam os ids `letra-a`, `letra-b`, … e substituem
automaticamente a versão procedural na datilologia (precisam estar no dicionário
com `"animacao"` ou salvas no aparelho).
